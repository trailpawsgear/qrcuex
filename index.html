This generates a static QR code: the content you type is baked directly into the pattern, so once it's printed it always points to the same thing. A version that lets you change the destination after printing, with scan counts over time, is coming as a separate upgrade once the small bit of server infrastructure it needs is in place.

Nothing you type here is sent anywhere, the code is generated locally in your browser.
